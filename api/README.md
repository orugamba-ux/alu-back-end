# api

Python scripts that pull employee TODO data from the JSONPlaceholder REST API
and save it as CSV and JSON.

- `0-gather_data_from_an_API.py` - prints the task progress of one employee
- `1-export_to_CSV.py` - writes that employee's tasks to `USER_ID.csv`
- `2-export_to_JSON.py` - writes that employee's tasks to `USER_ID.json`
- `3-dictionary_of_list_of_dictionaries.py` - writes every employee's tasks to
  `todo_all_employees.json`
